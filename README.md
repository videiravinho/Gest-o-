# Videira Gestão

Web app de gestão da Videira Vinhoteca, responsivo para iPhone/PWA e desktop.

## Primeira base
- Dashboard inspirado nas referências fornecidas pelo proprietário, com identidade própria da Videira.
- Produtos e edição de custos/preços.
- Calculadora inicial de markup, margem e sugestão de venda.
- Configurações de taxa de cartão, embalagem por garrafa, margem-alvo e gastos fixos.
- Financeiro e pedidos preparados para evolução.
- Persistência local para prototipagem.

## Próximas integrações
Supabase para autenticação e banco de dados; Vercel para deploy; módulos de despesas, estoque, vendas, clientes e relatórios.

## Desenvolvimento
```bash
npm install
npm run dev
```
